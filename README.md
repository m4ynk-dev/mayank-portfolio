# Mayank — Afterhours Portfolio

A Next.js App Router portfolio inspired by late-night indie music, nostalgic sunset colors, and lo-fi editorial design.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

1. In `app/page.js`, replace `REPLACE-WITH-YOUR-EMAIL@example.com` with your real email address.
2. Update the project cards, descriptions, and repository URLs to match your latest work.
3. Change the skills list to reflect what you currently use.
4. Run `npm run build` before deploying.

The music panel changes the displayed track and animates its visualizer; it does not stream or play audio.
